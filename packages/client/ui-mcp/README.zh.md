# dsh-client-ui-mcp

[English](README.md) | 中文

MCP 服务器界面：一个设置页面，列出所有向宿主上报的 MCP 服务器——逐行重连、对用户添加的服务器移除、以及添加表单——以及 `/mcp` 装饰，把宿主命令的裸调用变成一个服务器列表弹窗。

## MCP 设置页面

一个设置页（`settings.section` id `mcp`，排序在其他功能页之后——接入外部工具服务器是部署级工作，不是逐会话配置）。列表是宿主 `mcp.list` 的拉取：所有上报的服务器（profile 声明的和用户管理的都包含在内），按名称排序，每行显示其生命周期状态和当前注册的工具。

- **重新连接** 要求某个上报的服务器断开并重建连接。一个无法到达端点的服务器会在宿主侧进入自己的重连循环，恢复期间一直保留在列表中，所以行的状态才是连接的真实情况，而不是按钮。
- **移除** 只存在于用户管理的行（`managed: true`）。Profile 服务器由部署声明——页面根本不提供操作，而不是放一个到线路上必然被拒绝的按钮。
- **添加** 以原始文本字段收集服务器定义（名称、传输方式、命令或 URL、参数、环境变量、请求头、超时），在提交时解析成线路规格：宿主重新校验名称和挂载，被拒绝的添加会让表单保持打开并显示宿主的答复。一个添加时无法连接的服务器仍会被添加——恢复期间以它自己的生命周期状态出现在列表中。

## /mcp 装饰

宿主保留 `mcp` 命令的目录行、参数声明和生命周期；装饰只替换裸调用的行为。弹窗列出每个上报的服务器，行详情显示其状态和工具数。选中某个服务器行会经过共享确认门——这个门就是用户要看到的状态展示，确认它执行与设置页按钮相同的重连。末尾一行通过面板控制器打开 MCP 设置页，那是唯一能添加服务器的地方。

读取不区分回环；写入则区分。`mcp.add`、`mcp.remove` 和 `mcp.reconnect` 是特权线路调用，由连接层固定到回环，而 `mcp.list` 不含秘密、对所有人开放——列表中没有任何 URL、请求头或凭证跨线路传输。

## 模型体验

间接的，通过用户添加的服务器：它们的工具一经宿主注册就变为模型可见，而 [`dsh-mcp-client`](../../mcp/mcp-client/README.md) 负责这些工具在模型面前的样子。

#### KV 缓存影响

无直接失效。移除一个服务器只为之后组建的会话注销其工具；已在运行的会话保留其前缀所建立的工具集。

## 已知限制与推迟工作

- **没有服务器实时监听** —— 列表在页面自身变更后和首次渲染时重新拉取；一个自行恢复或恶化的服务器要等到下一次拉取才可见，而不是按事件即时可见。
- **同一时刻只有一个重连** —— 一个重连进行中时第二次按压是空操作；第一次重连后的列表重读已经回答了第二次按压想问的问题。
- **添加表单仅限回环** —— 在非回环页面上，特权调用会被连接层拒绝，所以添加或移除服务器需要一个连接宿主的本地浏览器。
