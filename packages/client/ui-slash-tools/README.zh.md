# @deepseek-ai/dsh-client-ui-slash-tools

[English](README.md) | 中文

Web 斜杠工具插件：向 `ctx.commandUi` 贡献三个表面——client 端的 `/clear` 动作、`/help` 弹层，以及挂在宿主 `/mode` 命令上的预设切换装饰。

`/clear`：斜杠菜单条目（以及裸 `/clear` 回车）在当前会话所在的 Workspace 与预设下新建一个空会话并打开它。原会话保留在列表中，不受影响；其引用工作区不会带过去。该动作只在非空当前会话上提供——空会话没有可清空的对话——并在执行时二次检查空状态，因此菜单扫描与选中之间变空的会话会直接 no-op。工作区归属从工作区列表快照按会话记账读取（与 New Session 复用扫描同一规则）；chat 会话不归属任何工作区，创建请求因此不带工作区。会话摘要中的 `agentPreset` 存在时随创建请求携带，使新会话运行与它相同的组成。命令面的 action 类型没有结果通道：创建或打开失败由命令服务记录日志、从不向用户展示——对“可以从菜单重试的便利快捷键”而言这正是合适语义。

`/help`：列出本会话可用斜杠命令的说明性弹层——读取合并菜单面（`CommandUiContract.menuRows`：宿主目录 + 可用的 client 贡献，按菜单顺序），以 `/名称` 行加行描述呈现。选中某行只关闭弹层，不执行任何命令。

`/mode`：装饰宿主 `/mode` 命令的裸调用，用预设名册弹层替代。名册来自 `agentPreset.list` 线读，省略损坏预设（选择器规则：损坏预设无法重组会话），并标记会话当前预设为 active；chat 会话不提供该弹层（宿主双向拒绝切换）。选中某行通过 commands Remote 提交完整的 `/mode <预设>` 行——宿主命令保留其目录行、参数认领与生命周期日志，并独占空闲守卫、chat 守卫与 `agent-preset/selected` 记录。

## 模型体验

### 清空会话

#### 模型看到的内容

本包没有任何模型可见内容。影响是间接的：新会话的首次提示词不携带对话历史——只有部署系统提示词、工作区解析出的文件，以及用户接下来的输入。

#### Token 影响

对话前缀重置为零；下一轮只支付自身提示词加部署基线。

#### KV Cache 影响

新会话的首次请求开启新的 provider 前缀，因此 provider 端缓存复用不会跨越清空；部署与工作区提示词的共享部分可能仍命中。

## 已知限制与暂缓事项

- **引用不会带过去**——列表摘要不携带引用轴，带引用工作区的会话被清空后引用丢失，新会话只归属其工作区。
- **失败仅记录日志**——action 类型没有结果通道；被拒绝的创建只记日志、不向用户播报。
- **菜单描述不随语言切换刷新**——`/clear` 与 `/help` 的描述是注册时读一次后由注册表持有的文本（命令服务只在重新注册时刷新，语言切换不刷新）。
