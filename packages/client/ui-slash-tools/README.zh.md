# @deepseek-ai/dsh-client-ui-slash-tools

[English](README.md) | 中文

Web 斜杠工具插件：行为完全在 client 端的斜杠入口。当前清单为 `/clear` 动作——斜杠菜单条目（以及裸 `/clear` 回车），在当前会话所在的 Workspace 与预设下新建一个空会话并打开它。原会话保留在列表中，不受影响；其引用工作区不会带过去。

该动作只在非空当前会话上提供——空会话没有可清空的对话——并在执行时二次检查空状态，因此菜单扫描与选中之间变空的会话会直接 no-op。工作区归属从工作区列表快照按会话记账读取（与 New Session 复用扫描同一规则）；chat 会话不归属任何工作区，创建请求因此不带工作区。会话摘要中的 `agentPreset` 存在时随创建请求携带，使新会话运行与它相同的组成。

命令面的 action 类型没有结果通道：创建或打开失败由命令服务记录日志、从不向用户展示——对“可以从菜单重试的便利快捷键”而言这正是合适语义。

## 模型体验

### 清空会话

#### 模型看到的内容

本包没有任何模型可见内容。影响是间接的：新会话的首次提示词不携带对话历史——只有部署系统提示词、工作区解析出的文件，以及用户接下来的输入。

#### Token 影响

对话前缀重置为零；下一轮只支付自身提示词加部署基线。

#### KV Cache 影响

新会话的首次请求开启新的 provider 前缀，因此 provider 端缓存复用不会跨越清空；部署与工作区提示词的共享部分可能仍命中。

## 已知限制与暂缓事项

- **引用不会带过去**——列表摘要不携带引用轴，带引用工作区的会话被清空后引用丢失，新会话只归属其工作区。
- **失败仅记录日志**——action 类型没有结果通道；被拒绝的创建只记日志、不向用户播报。
